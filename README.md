# HealthGuard AI – Smart Health Risk Predictor

HealthGuard AI is an AI/ML-based healthcare prediction application developed using Python, Streamlit, SQLite, and Machine Learning.

## Features
- Add Patient Record
- View Patient Data
- Update Patient
- Delete Patient
- AI-based Health Prediction
- SQLite Database Storage
- Data Validation

## Technologies Used
- Python
- Streamlit
- Scikit-Learn
- SQLite
- Pandas
- Joblib

## Machine Learning Model
Random Forest Classifier

## How to Run Project

Install dependencies:

pip install -r requirements.txt

Train model:

python train_model.py

Run app:

streamlit run app.py
